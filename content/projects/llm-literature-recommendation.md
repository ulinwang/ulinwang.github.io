## 项目简介

国家级大学生创新训练项目，以「良好」等级结项。

## 研究内容

- 使用 **LLaMA-Factory** 微调 **Qwen2.5-14B**
- 基于 **citeulike-a** 数据集设计 Prompt 模板与正负样本构造策略
- 以 **Precision / Recall / F1** 为核心指标迭代优化推荐效果
- 实现 **Agent 对话式推荐**：多轮交互中理解用户研究兴趣并推荐文献
